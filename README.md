# Expense Tracker API

A Spring Boot backend project for managing expenses using REST APIs.

## Features
- Add expense
- Get all expenses
- Update expense
- Delete expense

## Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- H2 Database
- Maven
- Postman

## API Endpoints

POST /expenses  
GET /expenses  
PUT /expenses/{id}  
DELETE /expenses/{id}
